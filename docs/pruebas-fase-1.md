# Pruebas a mano de la fase 1 (versión de Mac, parte común)

Para hacer con el instalador de prueba, en la iglesia o en la PC del culto.
La fase 1 reordenó el código por dentro: **nada de esto debería verse
distinto**. Si algo se ve o se comporta diferente que en la versión de
siempre, anotalo (qué hiciste y qué pasó).

Va primero lo que más se movió.

## 1. Las ventanas que cambiaron por dentro (tanda 7)

### Diseñador de canciones
- [ ] Abrirlo sólo para mirar y cerrar con Cancelar: la canción queda igual.
- [ ] Abrirlo, mirar, y Guardar sin tocar nada: las diapositivas siguen el tema como antes.
- [ ] Cambiar la letra de una diapositiva (doble clic sobre el texto): las otras siguen el tema.
- [ ] Agregar dos cuadros extra: escribir en cada uno, cambiar el orden (adelante / atrás) y quitar uno.
- [ ] Mover la caja con el mouse, con las flechas (Ctrl para pasos chicos) y estirarla con las manijas.
- [ ] Tab y Shift+Tab pasan de un cuadro a otro.
- [ ] «Aplicar a todas»: copia el formato, **no** copia los cuadros extra.
- [ ] «Restablecer» deja la diapositiva como el tema.
- [ ] Cancelar después de cambiar cosas: no queda nada.

### Diseñador de escenario
- [ ] Crear, duplicar, cambiar el nombre y borrar un escenario.
- [ ] Borrar el último que queda: dice «Tiene que quedar al menos un escenario.»
- [ ] Cajas: agregar, mover con el mouse, con las flechas y con las manijas; duplicar y borrar.
- [ ] «Usar este» cambia el que se ve en la pantalla de escenario.
- [ ] Guardar, y otra vez con Cancelar: Cancelar no cambia nada.

### Estilos de transmisión (OBS)
- [ ] Cambiar algo y Guardar: OBS lo toma.
- [ ] Cambiar algo y cerrar con la X: OBS vuelve a lo de antes.
- [ ] Elegir «Imagen o video…» y cancelar el archivo: el fondo queda transparente.
- [ ] Se abre desde «Salida para OBS» (botón de estilos) y desde el menú Transmisión.

### Ventana principal
- [ ] Cambiar el ancho de los paneles, maximizar, invertir lados, plegar paneles y pasar a diseño de aprendizaje o avanzado. Cerrar y abrir el programa: todo queda como lo dejaste.
- [ ] «Transiciones…» se abre desde el menú y desde Ajustes.
- [ ] «Reiniciar el sonido» muestra el aviso abajo y la música vuelve a sonar.

### Buscar letra en internet
- [ ] Buscar por nombre y por una frase de la letra.
- [ ] Al elegir un resultado se ve «N diapositivas».
- [ ] Mientras trae la letra, el botón Importar está apagado (es a propósito); cuando llega, se prende.
- [ ] Con un título que ya tenés, avisa y al importar pregunta qué hacer.
- [ ] Después de importar, aparece el tilde en el resultado.

### Propiedades de un medio (fondo, imagen o video)
- [ ] Zoom con la rueda, mover con el mouse y con las flechas (Shift para pasos grandes).
- [ ] Poner una fecha de evento: abajo dice cuándo pasa a «Eventos pasados».
- [ ] Guardar; después abrir y Cancelar sin cambios: queda igual.

### Logos
- [ ] Crear uno: el nombre queda seleccionado para escribir.
- [ ] Arrastrar el logo en la vista previa: se guarda solo un momento después de soltar.
- [ ] Elegir una imagen: el logo toma el nombre del archivo.
- [ ] Eliminar uno y cambiar el orden (subir / bajar).

### Pixabay
- [ ] Buscar con una sola letra: dice «Escribí qué fondo buscás.»
- [ ] Pasar de videos a fotos, y «Ver más resultados».
- [ ] Las miniaturas se ven.
- [ ] Elegir dos: el botón dice «Bajar 2»; bajarlas y verlas en la pestaña.

### Importar canciones (ProPresenter o EasyWorship)
- [ ] Dice cuántas encuentra de cada programa.
- [ ] Elegir a mano una carpeta que no sirve: avisa.
- [ ] Importar: al final muestra el resumen en la barra de abajo.

### Papelera
- [ ] Restaurar una canción: vuelve a la biblioteca.
- [ ] «Borrar del todo» y Cancelar: no borra nada.
- [ ] «Vaciar la papelera»: el aviso dice la cantidad correcta.

## 2. Lo que hay que mirar a ojo (tanda 5)
- [ ] **Biblia en cuadrícula:** los colores de las fichas de los libros son los de siempre (Antiguo y Nuevo Testamento, la ficha elegida).
- [ ] **Cuadrito en vivo:** con un video de fondo, el cuadrito de «En vivo» del operador muestra el video.
- [ ] **Biblias repetidas:** bajar o importar una Biblia que ya tenés. La pregunta ahora sale con el estilo de los demás avisos. Con tres botones, cerrarla con la X es Cancelar; con dos, es No.
- [ ] Ctrl+clic donde se usaba (elegir varios) sigue funcionando.
- [ ] Filtrar la lista de canciones escribiendo en el buscador.
