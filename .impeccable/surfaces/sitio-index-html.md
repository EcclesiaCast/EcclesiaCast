## Scope

`sitio/index.html` (landing, Persuade) and `sitio/privacidad.html` (Read). Visitor: a non-technical church operator or pastor deciding whether to download.

## Direction contract

THESIS: The page is a projection: the visitor sees EcclesiaCast's real output before reading a word, and passes its slides with the arrow keys like an operator. It refuses the category default of headline + floating app mockup + three icon cards.

OWN-WORLD: The darkened sanctuary and the projector's light. Night navy (#0B1A33, #13294B) fields, a warm gold beam (#F4B942) as the only accent, a cool off-white ground for reading, white "screen" frames with soft depth. System type (Segoe UI on Windows, the program's own face), heavy weight for headlines.

STORY: Understand in one viewport that it does songs and the Bible, free. Believe it because every image is the real program and the page says the uncomfortable truths (beta, unsigned, one church). Download, or learn how to install past the Windows warning.

FIRST VIEWPORT: Desktop: left 45% headline, one paragraph, the large gold «Descargar para Windows» button with version/size/OS under it and the beta line; right 55% a 16:9 projected screen lit by a beam from a small gold light at its left, cycling real output captures (song, Bible in two versions, video background, musicians' screen) with ◀ ▶ controls and a hint that the keyboard arrows work. Mobile: text, button, then the screen full width.

FORM: Persuade landing; direction pinned by the user-approved proposal (`docs/sitio-web-propuesta.md`); concept-seed not run because the brief pinned palette, type and motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
