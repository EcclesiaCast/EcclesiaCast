# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (the website in `sitio/`; the program itself is a native Windows WPF app)

## Stack

Static HTML and CSS with a little plain JavaScript, no dependencies, published to
GitHub Pages by a GitHub Actions workflow (decided by Alexis, 15/10/2026).

## Users

Projection operators and pastors of small Spanish-speaking churches (Uruguay,
Argentina and the rest of Latin America). Not technical; today they use
PowerPoint or paid programs, and they distrust an installer that Windows warns
about. Everything is written in Rioplatense Spanish, plain and without jargon.

## Product Purpose

EcclesiaCast is free, open-source (GPL-3.0) projection software for churches:
song lyrics, the Bible in one or two versions at once, image and video
backgrounds, announcements and the service playlist, in one Windows program.
The website exists to let a church see what it does and download it, and to
gather the public visibility the free code-signing programme asked for.

## Positioning

One free program that does songs and the Bible together, in Spanish, that
works without internet, made and used in a real church (Iglesia Pan de Vida,
Iglesia de Dios Misiones Mundiales, Montevideo, Uruguay).

## Capabilities and Constraints

- The installer is **not code-signed**; Windows shows «Windows protegió su PC».
  Say it plainly; never claim it is signed or endorsed by SignPath.
- It is a **beta** used by **one** church. Never say «muchas iglesias».
- Only features already used in a service are shown; ideas (NDI, Google Slides
  links) are never mentioned.
- No copyrighted Bible text (RVR1960, NVI…) or modern song lyrics in images:
  only the free Bibles (RV1909, BLM, VBL) and public-domain hymns.
- The site costs nothing: GitHub Pages, no paid domain, no external services,
  fonts or analytics, no cookies, no forms.

## Brand Commitments

- New logo (15/10/2026): a white screen outline with a gold flame on a navy
  rounded square (`sitio/img/logo.svg`). The old cross icon is retired.
- Author and maintainer: Alexis Pérez (@alexisperez7). Public contact e-mail
  as an «Escribirme» link in the footer; bugs and questions go to GitHub issues.
- No mention that the code is written with AI help (Alexis's decision).

## Evidence on Hand

Real screenshots and a 40-second demo video taken from the program running a
separate test library (`sitio/img/`, `sitio/video/`). There are no
testimonials, reviews, star counts or press: never invent any.

## Product Principles

- Tell the truth first; trust is the product.
- Show the program working instead of describing it.
- Plain words for people who are not technical.
- Free means free: nothing that costs money or tracks visitors.
